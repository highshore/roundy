# Roundy Copy and Terminology Guide

This file is the source of truth for product terminology and UI copy across Roundy code and Figma.

## 1. Canonical Product Terms

Use these terms consistently.

| Meaning | Use | Avoid |
| --- | --- | --- |
| A scheduled Roundy gathering | **Event** | night, room, experience, session |
| The two Roundy offerings | **Event Type** or **Format** | experience type |
| Dating-format event | **1:1 Mingle** | speed dating, dating night, dating room |
| Discussion-format event | **Business Talk** | networking night, networking room |
| Physical location | **Venue** | room, spot |
| People attending | **Attendees** or **Participants** | guests, crowd |
| Available capacity | **Places Left** | spots left, seats left when avoidable |
| Main landing page | **Discover** | home feed |
| Event listing page | **Events** | browse, calendar |
| Post-event mutual connection | **Match** | connection when referring to the product result |

### Core rule

When referring to something a user can browse, join, apply to, register for, or attend, call it an **Event**.

Do not replace **Event** with metaphorical language such as **night**, **room**, or **experience** in product UI copy.

Metaphorical language can appear in long-form brand storytelling only when it is clearly not naming a product object.

## 2. Heading Style

All user-facing headings use **Title Case**.

Do not end headings with punctuation.

Correct:
- Two Ways to Meet, Both Happen Offline
- Pick Your Kind of Event
- Upcoming in Seoul
- How Roundy Works
- Choose Your Event

Incorrect:
- Two ways to meet. Both happen offline.
- Pick your kind of night
- How Roundy works.
- Start with the room.

### Heading punctuation

Do not use terminal:
- periods
- exclamation marks
- question marks
- colons

Commas are allowed when they are grammatically useful inside the heading.

## 3. Body Copy

Body copy uses normal sentence case and normal punctuation.

Prefer:
- concrete language
- short sentences
- direct product terminology
- specific descriptions of what happens

Avoid:
- vague lifestyle language
- excessive metaphors
- generic startup copy
- replacing product nouns with poetic substitutes

## 4. Buttons and Links

Buttons and text links use concise sentence case unless a platform convention requires otherwise.

Examples:
- Explore events
- See all events
- How 1:1 Mingle works
- How Business Talk works
- Complete profile to join

Do not add terminal punctuation.

## 5. Roundy-Specific Naming

Always write:
- Roundy
- Discover
- Events
- 1:1 Mingle
- Business Talk
- My Events
- Matches
- Profile

Do not casually rename navigation labels or event types during redesigns.

## 6. Copy Review Checklist

Before finishing any UI design or implementation:

1. Search visible copy for **night**, **room**, **experience**, and **session**.
2. Replace them with **Event**, **Event Type**, **Format**, or **Venue** when referring to product objects.
3. Check every heading for Title Case.
4. Remove terminal punctuation from headings.
5. Keep button labels concise and without terminal punctuation.
6. Verify English and Korean convey the same product meaning.
7. Do not invent new terminology when an existing Roundy term already exists.
